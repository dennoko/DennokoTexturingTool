# Dennoko Texturing Tool 使用方法

Dennoko Texturing Tool は、Unity内でレイヤーベースのテクスチャ編集および合成を行うためのツールです。GPUまたはCPUを利用して、複数のテクスチャや色をブレンドし、各種モディファイアを適用した結果をPNGとして書き出すことができます。

## 1. セットアップ

### ウィンドウを開く
Unityメニューの `dennokoworks > Texturing Tool` を選択して、ツールウィンドウを開きます。

### 設定アセットの作成
1. Projectウィンドウで右クリックし、 `Create > dennokoworks > Texturing Tool Config` を選択して、新しい設定アセット（ScriptableObject）を作成します。
2. 作成したアセットをツールウィンドウの **Config** フィールドにドラッグ＆ドロップします。

## 2. キャンバス設定

ウィンドウ上部のキャンバス設定セクションで、出力テクスチャのサイズを変更できます。
- **Width / Height**: 256px から 4096px までのプリセットから選択可能です。

## 3. レイヤー管理

**Layers** セクションでは、テクスチャの重なりを管理します。

- **追加 / 削除**: `+` ボタンで新規レイヤーを追加し、 `✕` ボタンで削除します。
- **有効化 / 無効化**: チェックボックスでレイヤーの表示/非表示を切り替えられます。
- **ブレンドモード**:
    - **Normal**: 通常の重ね合わせ。
    - **Add**: 加算。
    - **Multiply**: 乗算。
    - **Overlay**: オーバーレイ。
    - **Screen**: スクリーン。

## 4. レイヤーパラメータ

選択したレイヤーの詳細設定を行います。

- **Type**:
    - **Texture**: 既存のテクスチャアセットを使用します。
    - **Color**: 単一の塗りつぶし色を使用します。
- **Opacity**: レイヤーの不透明度（0～1）を調整します。
- **Tiling Scale / Offset**: テクスチャの繰り返しと位置を調整します。
- **ID Mask**:
    - **Use ID Mask**: チェックをいれると、特定のメッシュの部位（SubMesh）のみにテクスチャを適用できます。
    - **SubMesh Index**: 適用対象とするサブメッシュのインデックスを指定します。

## 5. モディファイア (Modifiers)

レイヤー単位、または全レイヤー合成後（Global）に適用できるフィルタ機能です。

- **Color Replace (色置換)**:
    - 指定した色 (`From`) を別の色 (`To`) に置き換えます。 `Threshold` で色の許容範囲を調整できます。
- **HSV (色調補正)**:
    - 色相 (Hue)、彩度 (Sat)、明度 (Val) を調整します。
- **Levels (レベル補正)**:
    - 入出力の最小値・最大値を調整してコントラストを制御します。
- **Edge Dilation (縁の拡張)**:
    - アルファチャンネルの縁を外側に広げます。テクスチャの継ぎ目（シーム）対策に有効です。

## 6. スナップショット履歴 (Snapshot History)

現在の設定状態を一時的に保存しておくことができます。
- **Take Snapshot**: 現在の状態をリストに保存します。
- **Restore**: 保存された状態を復元します。
- **Clear All**: 履歴をすべて削除します。

## 7. 書き出し (Export)

- **Export Path**: 書き出し先のパスを指定します（デフォルトは `Assets/Generated/output.png`）。
- **Run Pipeline**: 合成処理を実行し、結果をファイルに保存します。成功するとウィンドウ内にプレビューが表示されます。
